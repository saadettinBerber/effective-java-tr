Chapter 4 — Item 15: Erişilebilirlik — Sabitler & Diziler
↩ Önceki sayfadan devam — Madde 15: public static final, dizi güvenlik açığı ve modüller

Genel (public) sınıfların örnek alanları (instance fields) nadiren genel olmalıdır (Madde 16). Bir alan final değilse veya değişebilir (mutable) bir nesneye referans ise — genel yaparak alanda saklanabilecek değerleri sınırlama yeteneğinden vazgeçersiniz. Ayrıca, alan değiştirildiğinde herhangi bir eylem alma yeteneğini de kaybedersiniz; böylece genel değişebilir alanlara sahip sınıflar genellikle iş parçacığı güvenli (thread-safe) değildir.

public static final alanları aracılığıyla sabitleri açığa çıkarabilirsiniz — bunların sınıfın sağladığı soyutlamanın ayrılmaz bir parçası olduğu varsayılır. Ancak, sıfır olmayan uzunluktaki bir dizi her zaman değişebilirdir; bu nedenle bir sınıfın genel statik final dizi alanına sahip olması yanlıştır:

Instance fields of public classes should rarely be public. You can expose constants via public static final fields. But a nonzero-length array is always mutable — never have a public static final array:

// Potansiyel güvenlik açığı! public static final Thing[] VALUES = { ... };

İki düzeltme yolu vardır. Diziyi özel yapıp değiştirilemez bir liste ekleyebilirsiniz:

Two fixes: make the array private and add an immutable list, or add a method that returns a copy:

private static final Thing[] PRIVATE_VALUES = { ... }; public static final List<Thing> VALUES = Collections.unmodifiableList(Arrays.asList(PRIVATE_VALUES)); // Alternatif: kopya döndüren metot public static final Thing[] values() { return PRIVATE_VALUES.clone(); }

Java 9'dan itibaren, modül sistemi (module system) iki ek örtük erişim düzeyi tanıtmıştır. Bir modül, module-info.java dosyasındaki exports bildirimleri aracılığıyla bazı paketlerini açıkça dışa aktarabilir (export). Dışa aktarılmamış paketlerdeki genel ve korumalı üyeler modül dışından erişilemez. Ancak bu koruma büyük ölçüde tavsiye niteliğindedir — modülün JAR dosyası modül yolu (module path) yerine sınıf yoluna (class path) konursa, tüm genel/korumalı üyeler normal erişilebilirliklerine geri döner.

Madde 15 — Özet: Erişilebilirliği mümkün olduğunca azaltın. Minimal bir genel API'yi dikkatle tasarlayın, sonra başıboş sınıfların, arayüzlerin veya üyelerin API'nin parçası olmasını önleyin. Sabit olarak hizmet eden public static final alanları dışında, genel sınıfların genel alanları olmamalıdır. public static final alanlarından referans verilen nesnelerin değişmez olduğundan emin olun.

Java 9's module system adds two implicit access levels via exports declarations. But module-based access is largely advisory.

Item 15 — Summary: Reduce accessibility as much as possible. No public fields except constants. Ensure objects referenced by public static final fields are immutable.

Item 16: In public classes, use accessor methods, not public fields

You may be tempted to write degenerate classes that only group fields:

Dizi Güvenlik Açığı

public static final Thing[] VALUES — dizi final olsa bile, dizi elemanları değişebilir! İstemci VALUES[0] = null yapabilir.

Çözüm 1: Collections.unmodifiableList() ile değiştirilemez liste dönün.

Çözüm 2: clone() ile dizinin kopyasını döndüren bir metot sağlayın.

Array elements are mutable even if the array reference is final. Return an unmodifiable list or a clone instead.

Java 9 Modül Sistemi

Java 9'da modüller, paketlerin üstünde bir katman ekler. module-info.java'da hangi paketlerin dışa aktarılacağını belirlersiniz. Ancak:

• JAR dosyası sınıf yoluna konursa modül koruması göz ardı edilir
• JDK dışında henüz yaygın kullanım alanı bulamadı
• Mevcut projelere entegrasyonu karmaşık

Java 9 modules add a layer above packages via module-info.java exports. But protection is advisory — placing JAR on classpath bypasses it.

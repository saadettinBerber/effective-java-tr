Madde 29: Jenerik Türleri Tercih Edin

Item 29: Favor generic types

Jenerik türler yazmak, istemci kodunda dönüşüm (cast) gerektiren türlere göre hem daha güvenli hem de kullanımı daha kolaydır. Yeni bir tür tasarladığınızda, olası istemcilerin dönüşüm yapmasını gerektirmeyen bir tür sağlayın. Bu genellikle türü jenerikleştirmek anlamına gelir.

Madde 7'deki basit yığın (stack) uygulamasını ele alalım — Object[] tabanlı versiyondu. Bunu jenerikleştirmek için iki yaklaşım vardır:

Yaklaşım 1: Object[]'i E[]'ye dönüştürün ve @SuppressWarnings ile bastırın. Daha okunabilir, daha kısa, daha yaygın.

Yaklaşım 2: Alanı Object[] olarak bırakın, her pop işleminde (E) dönüşümü yapın. Tür silme ile E çalışma zamanında Object olduğundan dönüşüm güvenlidir — ancak her erişimde dönüşüm gerekir.

Generic types are safer and easier than types requiring casts. Two approaches to generify a Stack: 1) Cast the array to E[] with SuppressWarnings. 2) Keep Object[] and cast on each pop.

// Jenerikleştirilmiş Stack — Yaklaşım 1 public class Stack<E> { private E[] elements; @SuppressWarnings("unchecked") public Stack() { elements = (E[]) new Object[DEFAULT_CAPACITY]; } public void push(E e) { ... } public E pop() { ... } }

Madde 30: Jenerik Metotları Tercih Edin

Item 30: Favor generic methods

Sınıflar jenerik olabildiği gibi, metotlar da jenerik olabilir. Statik yardımcı metotlar jenerikleştirmeye özellikle uygundur. Collections'daki tüm "algoritma" metotları (binarySearch, sort) jeneriktir.

Methods can also be generic. Static utility methods are especially good candidates.

// Jenerik metot — iki kümenin birleşimi public static <E> Set<E> union(Set<E> s1, Set<E> s2) { Set<E> result = new HashSet<>(s1); result.addAll(s2); return result; }

Özyinelemeli tür sınırı (recursive type bound): <E extends Comparable<E>> — "Kendisiyle karşılaştırılabilir herhangi bir E türü." Her Comparable kullanan metotta yaygındır:

Recursive type bound: <E extends Comparable<E>> — "any type E that is comparable to itself."

public static <E extends Comparable<E>> E max(Collection<E> c) { ... }

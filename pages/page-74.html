Chapter 6 — Enum ve Anotasyonlar / Enums and Annotations

Bölüm 6: Enum'lar ve Anotasyonlar

Java, özel amaçlı iki referans türü ailesini destekler: enum türü adı verilen bir sınıf çeşidi ve anotasyon türü adı verilen bir arayüz çeşidi. Bu bölüm, bu tür ailelerini en iyi şekilde kullanmak için yönergeler içerir.

Java supports enum types (a class variant) and annotation types (an interface variant). This chapter covers best practices for both.

Madde 34: int Sabitleri Yerine Enum Türlerini Kullanın

Item 34: Use enums instead of int constants

Enum türlerinden önce, sabit kümeleri temsil etmek için int enum kalıbı kullanılırdı — tür güvenliği olmayan, ifade gücü zayıf bir kalıp:

Before enums, the int enum pattern was used — no type safety, no expressiveness:

// int enum kalıbı — KULLANMAYIN! public static final int APPLE_FUJI = 0; public static final int APPLE_PIPPIN = 1; public static final int ORANGE_NAVEL = 0; // APPLE_FUJI == ORANGE_NAVEL → true! (yanlış)

Java'nın enum türleri, C/C++ enum'larından çok daha güçlüdür — tam teşekküllü sınıflardır. Her sabit, sınıfının tek bir örneğidir (instance-controlled). Enum türleri:

• Derleme zamanı tür güvenliği sağlar — farklı enum türlerini karıştıramazsınız
• Kendi ad alanları (namespace) vardır — aynı isimli sabitler farklı enum'larda olabilir
• Keyfi (arbitrary) metotlar ve alanlar eklenebilir, arayüzler uygulanabilir
• toString() yazdırılabilir isimler verir, values() ile tüm sabitler dolaşılabilir

Sabit-özel metot uygulamaları (constant-specific method implementations): Her enum sabiti kendi davranışını tanımlayabilir — soyut metot bildirin, her sabit ezsin:

Java enums are full-fledged classes. They provide type safety, namespaces, methods, fields, and can implement interfaces. Constant-specific method implementations let each constant define its own behavior.

public enum Operation { PLUS("+") { public double apply(double x, double y) { return x + y; } }, MINUS("-") { public double apply(double x, double y) { return x - y; } }, TIMES("*") { public double apply(double x, double y) { return x * y; } }, DIVIDE("/") { public double apply(double x, double y) { return x / y; } }; private final String symbol; Operation(String symbol) { this.symbol = symbol; } public abstract double apply(double x, double y); }

Madde 35: Sıra Numaraları Yerine Örnek Alanlarını Kullanın

Item 35: Use instance fields instead of ordinals

Tüm enum'ların bir ordinal() metodu vardır — enum sabitinin türü içindeki sıra konumunu döndürür. Bu değerlere asla güvenmeyin! Sabitler yeniden sıralandığında kod bozulur. Bunun yerine bir örnek alanı saklayın:

Never derive a value from ordinal() — reordering constants breaks code. Use an instance field instead.

// KÖTÜ — ordinal() kullanma! public int numberOfMusicians() { return ordinal() + 1; } // İYİ — örnek alanı kullan private final int numberOfMusicians; Ensemble(int size) { this.numberOfMusicians = size; } public int numberOfMusicians() { return numberOfMusicians; }

🔍 Kavramlar: 🔍 Concepts:

Java Enum = Tam Sınıf

Java enum'ları C/C++'daki basit tamsayı sabitlerinden çok farklıdır:

• Her sabit sınıfının tek, değişmez örneğidir
• Alanlar, metotlar, yapıcılar eklenebilir
• Arayüzler uygulanabilir
• Her sabitin kendi davranışı olabilir (sabit-özel metotlar)

Java enums are full classes: each constant is a singleton instance, can have fields, methods, constructors, implement interfaces, and have constant-specific behavior.

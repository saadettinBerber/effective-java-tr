Madde 32: Jenerikleri ve Varargs'ı Dikkatli Birleştirin

Item 32: Combine generics and varargs judiciously

Varargs metotları ve jenerikler birlikte iyi çalışmaz çünkü varargs jenerik veya parametreli türde bir varargs parametresi bildirildiğinde yığın kirliliği (heap pollution) riski oluşur. Tür güvenliği ihlal edilebilir ve ClassCastException beklenmedik bir noktada atılabilir.

Java 7'de eklenen @SafeVarargs notasyonu, yazar tarafından metodu güvenli olarak onaylanan jenerik varargs metotlarında uyarıyı bastırır. Bir metodu @SafeVarargs ile işaretlemek için iki koşulun sağlanması gerekir:

1. Metot varargs dizisine hiçbir şey kaydetmemelidir.
2. Dizinin (veya bir kopyasının) referansı güvenilmeyen koda kaçmamalıdır.

Kural: Jenerik veya parametreli türde varargs parametresi alan her metoda @SafeVarargs ekleyin — bu, kullanıcılarının gereksiz uyarılarla uğraşmasını önler. Alternatif olarak varargs yerine List parametresi kullanın.

Varargs + generics = heap pollution risk. Use @SafeVarargs when: 1) Method doesn't store into the varargs array, and 2) No reference to the array escapes. Alternative: use List instead of varargs.

Madde 33: Tür Güvenli Heterojen Kapsayıcıları Düşünün

Item 33: Consider typesafe heterogeneous containers

Jeneriklerin yaygın kullanımlarında (Set<E>, Map<K,V>) kapsayıcı başına sabit sayıda tür parametresi vardır. Ancak bazen daha fazla esnekliğe ihtiyaç duyarsınız — kapsayıcı yerine anahtarı parametreleştirerek bunu başarabilirsiniz. Bu kalıba tür güvenli heterojen kapsayıcı (typesafe heterogeneous container) denir:

Instead of parameterizing the container, parameterize the key. This is the typesafe heterogeneous container pattern:

// Tür güvenli heterojen kapsayıcı — API public class Favorites { private Map<Class<?>, Object> favorites = new HashMap<>(); public <T> void putFavorite(Class<T> type, T instance) { favorites.put(Objects.requireNonNull(type), instance); } public <T> T getFavorite(Class<T> type) { return type.cast(favorites.get(type)); } } // Kullanım Favorites f = new Favorites(); f.putFavorite(String.class, "Java"); f.putFavorite(Integer.class, 0xcafebabe); String s = f.getFavorite(String.class); // Dönüşüm yok!

Class<T> nesnesi burada tür belirteci (type token) rolü oynar. Favorites sınıfı dahili olarak Map<Class<?>, Object> kullanır — joker tür anahtar tarafında olduğundan farklı türler aynı haritada saklanabilir.

Tür Belirteci (Type Token)

Bir Class<T> nesnesi, çalışma zamanında tür bilgisini taşımak için tür belirteci olarak kullanılır. Bu, tür silmesini aşmanın bir yoludur:

• String.class → Class<String> türünde
• Integer.class → Class<Integer> türünde

Heterojen kapsayıcılarda anahtar olarak kullanılır. type.cast() ile güvenli dönüşüm yapılır.

A Class<T> object used as a type token carries runtime type info, bypassing erasure. Used as keys in heterogeneous containers.

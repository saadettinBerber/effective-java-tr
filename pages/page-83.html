Chapter 11 — Eşzamanlılık (Concurrency)

Bölüm 11: Eşzamanlılık

Madde 78 — Paylaşılan değiştirilebilir veriye erişimi senkronize edin: synchronized yalnızca karşılıklı dışlama (mutual exclusion) sağlamaz, aynı zamanda iş parçacıkları arası güvenilir iletişim garantisi verir. Bir iş parçacığının yaptığı değişiklikler senkronizasyon olmadan diğer iş parçacıklarına görünmeyebilir. En basit çözüm: paylaşılan değiştirilebilir veriyi paylaşmama. Değişmez (immutable) veriyi paylaşın. Verilecekse volatile veya AtomicLong kullanın.

Madde 79 — Aşırı senkronizasyondan kaçının: Senkronize blok içinde asla yabancı metot (alien method) çağırmayın — kilitlenme (deadlock) veya veri bozulması riski! CopyOnWriteArrayList gibi eşzamanlı koleksiyonlar kullanarak kilit içinden dışarı taşıyın.

Madde 80 — İş parçacıkları yerine yürütücüleri, görevleri ve stream'leri tercih edin: ExecutorService kullanın. Doğrudan Thread oluşturmak yerine Executors.newFixedThreadPool(), newCachedThreadPool() veya newSingleThreadExecutor() tercih edin.

Madde 81 — wait/notify yerine eşzamanlılık yardımcılarını tercih edin: ConcurrentHashMap, BlockingQueue, CountDownLatch, Semaphore gibi yüksek düzeyli yardımcıları kullanın. wait/notify kullanmak zorunda kalırsanız, wait'i her zaman bir döngü içinde çağırın.

// wait her zaman döngü içinde! synchronized (obj) { while (!condition) obj.wait(); }

Madde 82 — İş parçacığı güvenliğini belgeleyin: Beş düzey: değişmez (immutable), koşulsuz iş parçacığı güvenli, koşullu iş parçacığı güvenli, iş parçacığı güvenli değil, iş parçacığı düşman. Lock alanlarını private final yapın — istemcinin senkronizasyonu bozmasını engelleyin.

Madde 83 — Tembel başlatmayı dikkatli kullanın: Çoğu alan tembel başlatma gerektirmez. Gerekiyorsa: statik alanlar için tembel başlatma tutucu sınıfı idiom'u, örnek alanlar için çift kontrollü kilitleme (double-check locking) kullanın:

// Tembel başlatma tutucu sınıfı (statik alanlar için) private static class FieldHolder { static final FieldType field = computeFieldValue(); } private static FieldType getField() { return FieldHolder.field; }

Madde 84 — İş parçacığı zamanlayıcısına bağımlı olmayın: Thread.yield() veya iş parçacığı öncelikleri güvenilir değildir. Thread.yield'in test dışında kullanımı yoktur. Programınızın doğruluğu zamanlayıcıya bağlı olmamalıdır.

Bölüm 11 — Özet: 7 kural — senkronizasyon, aşırı senkronizasyondan kaçınma, yürütücüler, eşzamanlılık yardımcıları, belgeleme, tembel başlatma ve zamanlayıcı bağımsızlığı.

Madde 27: Denetimsiz Uyarıları Ortadan Kaldırın

Item 27: Eliminate unchecked warnings

Jeneriklerle programladığınızda birçok derleyici uyarısı göreceksiniz: denetimsiz dönüşüm (unchecked cast), denetimsiz metot çağrısı, denetimsiz parametreli vararg türü ve denetimsiz tür dönüşümü uyarıları. Ortadan kaldırabildiğiniz her denetimsiz uyarıyı ortadan kaldırın — kodunuzun tür güvenli (typesafe) olduğundan emin olun.

Bir uyarıyı ortadan kaldıramıyorsanız ama kodun güvenli olduğunu kanıtlayabiliyorsanız, o zaman (ve ancak o zaman) @SuppressWarnings("unchecked") ile bastırın. Bastırma notasyonunu her zaman mümkün olan en dar kapsamda kullanın — hiçbir zaman sınıf düzeyinde değil!

Eliminate every unchecked warning you can. If you can prove code is typesafe, suppress with @SuppressWarnings("unchecked") on the narrowest possible scope. Never on an entire class.

// Kapsam daraltma — yerel değişkene taşıyın public <T> T[] toArray(T[] a) { if (a.length < size) { @SuppressWarnings("unchecked") T[] result = (T[]) Arrays.copyOf(elements, size, a.getClass()); return result; // Bastırma sadece bu satırda } ... }

@SuppressWarnings kullandığınız her yerde neden güvenli olduğunu açıklayan bir yorum ekleyin.

Madde 28: Diziler Yerine Listeleri Tercih Edin

Item 28: Prefer lists to arrays

Diziler jeneriklerden iki önemli şekilde ayrılır:

1. Diziler kovaryant (covariant): Sub, Super'in alt türüyse, Sub[] de Super[]'in alt türüdür. Jenerikler değişmez (invariant): List<Sub>, List<Super>'in ne alt türü ne de üst türüdür.

Arrays are covariant (Sub[] is subtype of Super[]). Generics are invariant (List<Sub> is unrelated to List<Super>).

// Çalışma zamanında başarısız olur! Object[] objectArray = new Long[1]; objectArray[0] = "Sığmam!"; // ArrayStoreException! // Derleme zamanında yakalar — tercih edin! List<Object> ol = new ArrayList<Long>(); // Derleme HATASI

2. Diziler somutlaştırılır (reified): Çalışma zamanında eleman türünü bilir ve zorunlu kılar. Jenerikler tür silme (erasure) ile uygulanır — tür bilgisi yalnızca derleme zamanında ve çalışma zamanında silinir. Bu nedenle jenerik diziler (örn. new List<String>[]) oluşturulamaz!

Bir jenerik dizi oluşturma hatası aldığınızda çözüm genellikle E[] yerine List<E> kullanmaktır. Biraz performans veya kısalık kaybedebilirsiniz, ama tür güvenliği ve birlikte çalışabilirlik kazanırsınız.

Arrays are reified (enforce type at runtime). Generics use erasure (types erased at runtime). You can't create generic arrays (new List<String>[]). When you get generic array creation errors, use List<E> instead of E[].

🔍 Kavramlar: 🔍 Concepts:

Kovaryans vs Değişmezlik

Kovaryant (covariant): Integer[], Number[]'in alt türüdür. Çalışma zamanında yanlış tür atanırsa ArrayStoreException fırlatılır.

Değişmez (invariant): List<Integer>, List<Number> ile ilişkisizdir. Yanlış kullanım derleme zamanında yakalanır — daha güvenli.

Covariant: Integer[] is subtype of Number[] — runtime errors. Invariant: List<Integer> unrelated to List<Number> — compile-time safety.

Tür Silme (Type Erasure)

Jenerikler tür silme ile uygulanır: Derleme zamanında tür kontrolü yapılır, çalışma zamanında tür parametreleri silinir. List<String> çalışma zamanında sadece List'tir. Bu nedenle:

• new T() yazamazsınız
• new List<String>[] oluşturamazsınız
• instanceof List<String> test edemezsiniz

Generics use erasure: type info exists at compile time, erased at runtime. Can't: new T(), new List<String>[], instanceof List<String>.

Zaman zaman birinci değer ikinciden küçükse negatif, eşitse sıfır, büyükse pozitif olan fark (difference) kullanan compareTo veya compare metotları görebilirsiniz:

Occasionally you may see compareTo or compare methods that rely on the difference between two values:

// BOZUK — fark tabanlı karşılaştırıcı — geçişliliği ihlal eder! static Comparator<Object> hashCodeOrder = new Comparator<>() { public int compare(Object o1, Object o2) { return o1.hashCode() - o2.hashCode(); // TEHLİKE! } };

Bu tekniği kullanmayın. Tamsayı taşması (integer overflow) ve IEEE 754 kayan nokta aritmetik artefaktları nedeniyle tehlikelerle doludur. Bunun yerine şu iki yaklaşımdan birini kullanın:

Do not use this technique. It is fraught with danger from integer overflow and IEEE 754 floating point artifacts. Use one of these instead:

// Statik compare metodu kullanan karşılaştırıcı static Comparator<Object> hashCodeOrder = new Comparator<>() { public int compare(Object o1, Object o2) { return Integer.compare(o1.hashCode(), o2.hashCode()); } }; // Comparator construction method kullanan karşılaştırıcı static Comparator<Object> hashCodeOrder = Comparator.comparingInt(o -> o.hashCode());
Madde 14 — Özet: Anlamlı bir sıralamaya sahip bir değer sınıfı uyguladığınızda, sınıfın Comparable arayüzünü uygulamasını sağlayın. Böylece örnekleri kolayca sıralanabilir, aranabilir ve karşılaştırma tabanlı koleksiyonlarda kullanılabilir. compareTo metotlarındaki alan değerlerini karşılaştırırken < ve > operatörlerini kullanmaktan kaçının. Bunun yerine, sarmalayıcı ilkel sınıflardaki statik compare metotlarını veya Comparator arayüzündeki karşılaştırıcı oluşturma metotlarını kullanın.

Fark Tabanlı Karşılaştırma Tuzağı

return a - b; yaklaşımı ilk bakışta doğru gibi görünür, ancak iki sorun barındırır:

1. Tamsayı taşması: a = Integer.MAX_VALUE ve b = -1 olduğunda, a - b taşar ve negatif bir değer döndürür — yanlış sonuç!

2. Kayan nokta artefaktları: float ve double için IEEE 754 kuralları nedeniyle beklenmeyen sonuçlar oluşabilir.

Çözüm: Her zaman Integer.compare(a, b), Double.compare(a, b) veya Comparator.comparingInt() kullanın.

return a - b can overflow for integers and has IEEE 754 artifacts for floats. Always use Integer.compare(a, b) or comparator construction methods.

Madde 36: Bit Alanları Yerine EnumSet Kullanın

Item 36: Use EnumSet instead of bit fields

Eskiden, sabit kümeleri geçmek ve üzerlerinde birleşim (union) / kesişim (intersection) işlemi yapmak için bit alanları (bit fields) kullanılırdı: text.applyStyles(STYLE_BOLD | STYLE_ITALIC). Bu yaklaşımın tüm int enum kalıbı dezavantajları vardır — artı yazdırılacak değerleri yorumlamak zordur.

java.util.EnumSet bunun yerine kullanılmalıdır — dahili olarak bit vektörü kullanır, bu nedenle bit alanları kadar hızlıdır:

Instead of bit fields (BOLD | ITALIC), use EnumSet — internally a bit vector, just as fast:

// EnumSet — bit alanlarının modern alternatifi public class Text { public enum Style { BOLD, ITALIC, UNDERLINE, STRIKETHROUGH } public void applyStyles(Set<Style> styles) { ... } } // Kullanım text.applyStyles(EnumSet.of(Style.BOLD, Style.ITALIC));

Madde 37: Sıra İndeksleme Yerine EnumMap Kullanın

Item 37: Use EnumMap instead of ordinal indexing

ordinal() değerini dizi indeksi olarak kullanmak yaygın ama tehlikeli bir kalıptır. EnumMap kullanın — dahili olarak bir dizi kullanır ama tür güvenli ve temizdir:

Don't use ordinal() as array index. Use EnumMap — internally an array but type-safe:

// KÖTÜ — ordinal() ile indeksleme Set<Plant>[] plantsByLifeCycle = (Set<Plant>[]) new Set[LifeCycle.values().length]; // İYİ — EnumMap Map<LifeCycle, Set<Plant>> plantsByLifeCycle = new EnumMap<>(LifeCycle.class);

Madde 38: Genişletilebilir Enum'ları Arayüzlerle Taklit Edin

Item 38: Emulate extensible enums with interfaces

Enum türleri genişletilemez — ve çoğu durumda bu iyidir. Ancak işlem kodları (operation codes) gibi durumlarda genişletilebilirlik gerekebilir. Çözüm: Enum'un bir arayüz uygulaması yapmak ve bu arayüzü API'de kullanmak:

Enums can't be extended. For opcode-like enums, have the enum implement an interface and use the interface in APIs:

public interface Operation { double apply(double x, double y); } public enum BasicOperation implements Operation { PLUS("+") { ... }, MINUS("-") { ... }; } public enum ExtendedOperation implements Operation { EXP("^") { ... }, REMAINDER("%") { ... }; }

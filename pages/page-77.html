Chapter 7 — Lambdalar ve Streamler

Bölüm 7: Lambdalar ve Streamler

Java 8'de fonksiyonel arayüzler (functional interfaces), lambdalar (lambdas) ve metot referansları (method references) eklendi; ayrıca bu olanakları paralel işleme ile kullanmak için Stream API tanıtıldı.

Java 8 added functional interfaces, lambdas, method references, and the Stream API for parallel processing.

Madde 42: Anonim Sınıflar Yerine Lambdaları Tercih Edin

Item 42: Prefer lambdas to anonymous classes

Eskiden, tek soyut metotlu arayüzler işlev türleri (function types) olarak kullanılırdı ve anonim sınıflarla oluşturulurdu. Java 8 ile artık lambdalar kullanın — çok daha kısa ve okunabilir:

Lambdas replaced anonymous classes for single-abstract-method interfaces — shorter and more readable:

// Anonim sınıf — artık eski yöntem Collections.sort(words, new Comparator<String>() { public int compare(String s1, String s2) { return Integer.compare(s1.length(), s2.length()); } }); // Lambda — Java 8+ Collections.sort(words, (s1, s2) -> Integer.compare(s1.length(), s2.length())); // Daha da kısa — metot referansı + comparingInt words.sort(comparingInt(String::length));

Lambda kuralları: Tür bildirimlerini atlayın (derleyici çıkarır). Lambdayı 3 satırdan kısa tutun. Lambda'nın this'i çevreleyen sınıfı ifade eder — kendi örneğine erişmeniz gerekiyorsa anonim sınıf kullanın. Lambda'lar serileştirilemez — buna ihtiyaç duyuyorsanız özel sınıf (private static nested class) kullanın.

Madde 43: Lambdalar Yerine Metot Referanslarını Tercih Edin

Item 43: Prefer method references to lambdas

Metot referansları genellikle lambdalardan daha kısa ve nettir. 5 tür metot referansı vardır:

• Statik: Integer::parseInt ↔ str -> Integer.parseInt(str)
• Sınırlı (bound): Instant.now()::isAfter ↔ t -> Instant.now().isAfter(t)
• Sınırsız (unbound): String::toLowerCase ↔ str -> str.toLowerCase()
• Sınıf yapıcısı: TreeMap<K,V>::new ↔ () -> new TreeMap<K,V>()
• Dizi yapıcısı: int[]::new ↔ len -> new int[len]

Metot referansı lambda'dan daha uzun veya daha az net olabiliyorsa lambda kullanın.

Madde 44: Standart Fonksiyonel Arayüzleri Tercih Edin

Item 44: Favor the use of standard functional interfaces

java.util.function paketinde 43 arayüz vardır ama 6 temel olanı bilin:

• UnaryOperator<T>: T apply(T t) — String::toLowerCase
• BinaryOperator<T>: T apply(T t1, T t2) — BigInteger::add
• Predicate<T>: boolean test(T t) — Collection::isEmpty
• Function<T,R>: R apply(T t) — Arrays::asList
• Supplier<T>: T get() — Instant::now
• Consumer<T>: void accept(T t) — System.out::println

Kendi fonksiyonel arayüzünüzü yazıyorsanız her zaman @FunctionalInterface notasyonunu ekleyin.

6 basic functional interfaces: UnaryOperator, BinaryOperator, Predicate, Function, Supplier, Consumer. Always annotate custom functional interfaces with @FunctionalInterface.

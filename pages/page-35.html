Sonuç (lesson) gayet açıktır: Kapatılması gereken kaynaklarla çalışırken, try-finally yerine her zaman try-with-resources'ı tercih edin. Ortaya çıkan kod daha kısa ve daha açıktır (clearer), ve ürettiği istisnalar çok daha yararlıdır. try-with-resources ifadesi, kapatılması gereken kaynaklarla doğru kod yazmayı kolaylaştırır — bu, try-finally kullanılarak pratikte neredeyse imkânsız olan bir şeydi.

The lesson is clear: Always use try-with-resources in preference to try-finally when working with resources that must be closed. The resulting code is shorter and clearer, and the exceptions that it generates are more useful. The try-with-resources statement makes it easy to write correct code using resources that must be closed, which was practically impossible using try-finally.

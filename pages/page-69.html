Chapter 5 — Jenerikler / Generics

Bölüm 5: Jenerikler

Java 5'ten beri jenerikler (generics) dilin ayrılmaz bir parçası olmuştur. Jeneriklerden önce, bir koleksiyondan okunan her nesneyi dönüştürmek (cast) gerekiyordu. Birisi yanlışlıkla yanlış türde bir nesne eklerse, çalışma zamanında dönüşümler başarısız olabilirdi. Jeneriklerle, derleyiciye bir koleksiyonun hangi türde nesne içermesi gerektiğini söylersiniz. Dönüşümleri sizin yerinize otomatik ekler ve derleme zamanında yanlış türde bir nesne eklemeye çalışırsanız sizi uyarır.

Since Java 5, generics are an integral part of the language. Before generics, every object from a collection had to be cast. With generics, the compiler inserts casts automatically and warns at compile time if you try to add the wrong type.

Madde 26: Ham Türleri Kullanmayın

Item 26: Don't use raw types

Bir sınıf veya arayüz bildirimi tür parametreleri (type parameters) içeriyorsa, buna jenerik sınıf veya jenerik arayüz denir — birlikte jenerik türler (generic types). Örneğin List arayüzü tek bir tür parametresi alır: List<E>. Her jenerik tür bir ham tür (raw type) tanımlar — tür parametresi olmadan kullanılan jenerik türdür: List.

Ham türler kullanmayın! Ham türler jeneriklerden önceki uyumluluk için vardır. Kullanılmaları durumunda jenerik sistemin tüm güvenlik ve ifade gücü avantajlarını kaybedersiniz:

A raw type is a generic type used without type parameters, like List instead of List<String>. Don't use raw types — they exist only for legacy compatibility.

// Ham tür — KULLANMAYIN! private final Collection stamps = ...; stamps.add(new Coin(...)); // Derleme hatası vermez! // Parametreli tür — güvenli private final Collection<Stamp> stamps = ...; stamps.add(new Coin(...)); // Derleme HATASI — doğru!

List (ham) vs List<Object>: List jenerik tür denetiminden tamamen çıkar; List<Object> ise açıkça herhangi bir nesneyi kabul ettiğini belirtir. List<String>'i List'e geçirebilirsiniz ama List<Object>'e geçiremezsiniz!

Sınırsız joker türler (unbounded wildcard types): Eleman türünü bilmiyorsanız veya önemsemiyorsanız Set<?> kullanın. Joker tür güvenlidir — null dışında hiçbir şey eklenemez.

İstisnalar: Ham türler iki yerde kullanılabilir: (1) class değişmezleri (List.class evet, List<String>.class hayır) ve (2) instanceof operatörü.

List opts out of generics; List<Object> explicitly accepts any object. Use Set<?> for unknown types. Only use raw types with .class literals and instanceof.

🔍 Kavramlar: 🔍 Concepts:

Ham Tür vs Joker Tür

Set (ham): Jenerik sistemi tamamen atlar — tehlikeli.
Set<?> (joker): Bilinmeyen türde elemanlar içerir — null hariç eleman ekleyemezsiniz → güvenli.
Set<Object>: Açıkça herhangi bir nesneyi kabul eder — güvenli.

Set (raw) opts out of generics. Set<?> (wildcard) is safe — can't add except null. Set<Object> explicitly accepts any type — safe.

Jenerik Terminoloji

Parametreli tür: List<String>
Gerçek tür parametresi: String
Jenerik tür: List<E>
Biçimsel tür parametresi: E
Sınırsız joker türü: List<?>
Ham tür: List
Sınırlı tür parametresi: <E extends Number>
Özyinelemeli tür sınırı: <T extends Comparable<T>>
